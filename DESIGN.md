# Agent Desktop design system

Reference: https://www.orgo.ai/ and its public product-preview.webp, inspected September 2026. Original branding and assets only.

Quiet, precise, dark desktop software: narrow rail, workspace breadcrumb, live desktop stage, right-side conversation. Background #090909; panels #111112; elevated #1a1a1c; borders #272729. Primary text #f5f5f5, secondary #99999f, muted #707078. Accent #b7f7cc; warning #edc582; error #f29b9b. Pair status colors with text.

System font stack; 4px spacing grid; 12px panel radii. Rail 64px, chat 380px; stage flexes. Under 1050px stack chat, under 700px prioritize monitoring. Respect reduced motion and show focus rings.

Screens: landing, authentication, onboarding, computers, live desktop, billing, team/settings, and reusable token trial enrollment. Empty states explain the next action. Never fabricate live desktop content or agent completion. Distinguish disconnected, stopped, provisioning, failed, awaiting approval, and capacity-full states.

Desktop: original landscape wallpaper, dark XFCE, small browser/files/terminal dock. Take control is an explicit mode transition.
